# Contributing to VisionKeyboard

Thank you for your interest in contributing to **VisionKeyboard**!

## Great Places to Contribute

- Add predictive text / autocorrect or backspace, space, and punctuation chords.
- Refine ARKit hand-tracking debounce and fingertip pinch thresholds.
- Integrate `PlaneDetectionView` for virtual surface typing.
- Add spatial audio cues and visual feedback for key confirmation.

## Workflow

1. Fork the repository and create a branch (`feat/...` or `fix/...`).
2. Open `VisionKeyboard.xcodeproj` in Xcode with the visionOS SDK and verify builds cleanly.
3. Keep changes focused and avoid committing `.DS_Store`, API keys, model weights, or user-specific IDE state (`xcuserdata/`).
4. Open a pull request describing what changed and how you verified it.
